# Documentos

Copias de documentos clave (leyes, memorias, resoluciones, artículos) cuando se pueden guardar, para que no se pierdan si el enlace original desaparece. Nombre sugerido: `AAAA-tipo-descripcion.pdf` (ej. `1881-ley-1130.pdf`). Cada documento guardado debe figurar también en `fuentes.md`.
