# Registro de fuentes

Cada fuente tiene un código único `F-####` que se usa en los archivos de las series. Los códigos nunca se reasignan ni se reutilizan para otra fuente.

**Niveles:** 1 = oficial · 2 = investigación numismática · 3 = mercado · 4 = comunidad

Formato de cada entrada:

```
### F-0001
- Título:
- Autor / institución:
- URL:
- Archivo (Internet Archive):
- Nivel:
- Consultada: AAAA-MM-DD
- Cita clave: "…"
- Usada en: serie NN, serie NN
```
